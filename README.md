# OTP Login App

## Description
A React + Django application where users register using their name and email. A unique login code is generated during registration and is required to complete checkout.

## Features
- User Registration
- Unique Login Code Generation
- Email Verification
- Checkout Verification
- Form Validation
- Responsive UI

## Tech Stack
Frontend:
- React.js
- Bootstrap
- Axios

Backend:
- Django
- Django REST Framework

Database:
- SQLite

## Deployment
- Render

## How It Works
1. User registers.
2. System generates a login code.
3. User enters registered email in checkout.
4. Login code is verified.
5. Checkout form is displayed.
6. Order is submitted successfully.
