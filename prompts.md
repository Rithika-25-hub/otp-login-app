# prompts.md

This file contains the prompts used during the development of the Email Recognition & Checkout System.

## Prompt 1
Create a Django REST API for user registration that accepts first name, last name, and email, generates a unique login code, and stores the user in the database.

## Prompt 2
Create a Django serializer and API endpoint to validate whether an email address belongs to a registered user.

## Prompt 3
Build a React registration page that connects to the registration API and displays the generated login code after successful registration.

## Prompt 4
Implement real-time email validation in React and trigger an API call when a complete email address is entered.

## Prompt 5
Create an email recognition feature that checks whether a user exists and displays a verification popup for registered users.

## Prompt 6
Create a Django API endpoint that verifies a user's login code using their email address.

## Prompt 7
Build a React popup modal that allows users to enter their login code and verify their identity.

## Prompt 8
Display a welcome message after successful login code verification.

## Prompt 9
Create a checkout model, serializer, and API endpoint that stores phone number and shipping address linked to a registered user.

## Prompt 10
Build a React checkout form that submits phone number and shipping address to the backend after successful verification.

## Prompt 11
Implement validation for:
- Email format
- Phone number (10 digits)
- Shipping address

## Prompt 12
Create a clean frontend UI using React and Bootstrap for registration, verification, and checkout flows.

## Prompt 13
Debug and resolve frontend-backend integration issues related to API requests, modal handling, form validation, and checkout submission.

## Prompt 14
Generate project documentation including README.md, requirements.txt guidance, API descriptions, and project setup instructions.
